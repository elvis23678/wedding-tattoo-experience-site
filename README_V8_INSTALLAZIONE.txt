WTE V8 - MULTIUTENTE

NOVITA
- Login personale con email e password
- Accesso proprietario compatibile con password Admin Cloud
- Cambio password obbligatorio al primo accesso
- Ruoli Admin e Collaboratrice
- Permessi personalizzabili
- Ultimo accesso, IP e registro accessi
- Reimpostazione password temporanea
- Copia automatica credenziali
- Disabilitazione ed eliminazione account
- Sessione persistente fino a 30 giorni
- Logout reale

INSTALLAZIONE
1. Caricare tutti i file nelle stesse posizioni.
2. Render > wte-cloud-api > Manual Deploy > Deploy latest commit.
3. Attendere il deploy dei siti statici.
4. Aprire admin.weddingtattooexperience.it.
5. Proprietario: lasciare vuota l'email e inserire la password Admin Cloud.
6. Collaboratrice: usare email e password temporanea.
7. Al primo accesso la collaboratrice deve creare una nuova password.

NOTA
Il recupero automatico tramite email non e ancora attivo. L'Admin può reimpostare
la password dalla sezione Impostazioni > Utenti e ruoli.
