INSTALLAZIONE
1. Conserva una copia del repository corrente.
2. Estrai questo ZIP.
3. Carica TUTTO il contenuto nella root del repository GitHub.
4. Accetta la sostituzione dei file con lo stesso nome.
5. Attendi il deploy verde su Render.
6. Apri /admin/ e crea il PIN al primo accesso.

IMPORTANTE
- Il PIN è un blocco locale utile a evitare accessi casuali, ma non è autenticazione server.
- Archivio e PDF restano nel browser/localStorage/IndexedDB del dispositivo.
- Per sicurezza reale e sincronizzazione tra dispositivi serve un backend con database.
